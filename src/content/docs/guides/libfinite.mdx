Welcome to the Infinite Developer Family! I'm so glad you or your project manager has decided to bring your project to Infinite. This documenation page will provide some information on how to use the Infinite API and how to build an Infinite Compliant game.

## Project Goals

The objective of Infinite Library is to create an abstractable, simple and lightweight development library for Infinite Game Developers that handles the complexities of interacting with the console behind simple, easy to understand functions while still giving developers freedom of choice to implement their own versions of these functions.

As a developer, you can easily mix and match the implementation of features provided by the Infinite SDK and your own implementations to create a virtually seamless transition to the Infinite hardware. If you want extended functionality of any libfinite function, you can always write a local version yourself. libfinite functions don't call on each other (with a few exceptions, such as [`finite_render_begin_oneshot_command`](/reference/finiterender/functions/finite_render_begin_oneshot_command/)) so you're free to do what you want (within reason).

## Engine Support

As of libfinite 0.8.0, no engines have native libfinite support (as engine support is a later focus) but you can still work with libfinite to bring support for the library in your custom engines.

## What's next for libfinite?

Our goal of getting libfinite stable is a lofty but important goal that will allow things like Engine support to be possible. Below is our goal for the next few versions of libfinite.

- 0.8.2 Targets
  - FiniteClock utility that provides shorthand clock utilities.

- 0.9.0 Targets
  - ALSA Audio Revamp to bring much needed improvements to audio
  - Additional FiniteUserAPI to improve user interation features and allow RESTful calls as a developer
  - FiniteLinkedAllocator to further improve the render API.

- 0.9.2 Targets
  - FiniteFS utility that brings proper filesystem integration into libfinite, allowing for relative imports
  - Additional ALSA Improvements to bring bluetooth Audio in using our Bluetooth implementation.
  - Bluetooth Controller support via our bluetooth implementation.

- 0.9.3 Targets
  - FiniteNotify to support notifications and popups
  - Controller popup revamp
